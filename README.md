El objetivo del workflow es exportar en un prompt adaptado para generar imágenes promocionales para mi emprendimiento.
Comenzamos con un mensaje estilo “Genera una imagen para promocionar el Lattafa Asad” que va a ser procesado por el nodo “Basic LLM Chain” con el objetivo de identificar y separar 2 objetos en un JSON: Perfume e idea semilla.
Generado el JSON con los objetos deseados, se busca el perfume en la base de datos en Notion para recabar información útil a la hora de confeccionar el prompt como por ejemplo: Notas de salida, notas de corazón, notas de fondo, ocasión ideal de uso, temporada de uso. 
Una vez recopilada la información pasamos por un condicional con 2 posibles caminos determinados por si el perfume fue encontrado o no. Si el perfume fue encontrado, continua con el workflow, si el perfume no fue encontrado, envía un mensaje por Telegram informando que el perfume no se encontró y da por finalizado el workflow. 
Continuando con flujo, luego de recabar información en la base de datos, se envía a un nodo de Gemini que recibe todos los datos necesarios para generar un prompt superdetallado para generar la imagen solicitada por el usuario: Nombre del perfume, idea del usuario, notas de salida, notas de corazón, notas de fondo, ocasión ideal de uso, temporal de uso; dando como resultado un prompt que se envía al usuario por Telegram quien aprueba o desaprueba la idea generada, determinando así el futuro del flujo: generar un http request para continuan con un webhook o desestimar el prompt generado.


*EL ERROR DEL HTTP REQUEST ES PRODUCTO DE QUE LOS FLUJOS (EMISOR Y RECEPTOR) no estan publicados.
